# ともしび — 呼吸で灯籠を流す

https://bubbleshaker.github.io/tomoshibi/

疲れた日の終わりに、スマホで 1〜5 分だけ遊ぶ呼吸のゲームです。

- 画面を **押している間に吸い**、**離してゆっくり吐く**。
- 吸うと岸辺の灯籠に火がともり、吐いているあいだ灯籠は水面を流れていきます。長く吐くほど灯籠は大きく、暖かく光ります。
- 呼吸を重ねると、蛍が集まり、星が増え、月が昇ります。
- 「目を閉じて」を選ぶと画面に触れなくても進み、音の高さ（吸うと上がり、吐くと下がる）に合わせて呼吸できます。

## なぜ呼吸なのか

吐く息を吸う息より長くした 1 分間に 6 回前後のゆっくりした呼吸は、心拍のゆらぎ（HRV）を大きくし、副交感神経の働きを高めることが知られています。
このゲームはその呼吸を、勝ち負けや失敗のない遊びにしました。テンポは「はじめて 3・5 秒」「ふつう 4・6 秒」「ゆったり 5・7 秒」から選べます。

息苦しさやめまいを感じたら、いつもの呼吸に戻してください。

## 作り

ビルドなしの HTML / CSS / ES Modules。音はすべて Web Audio で合成しています。

- `js/breath.js` 呼吸の状態機械
- `js/scene.js` 夜の水面の描画（canvas 2D、30fps）
- `js/audio.js` ドローン・水音・風・鈴
- `js/main.js` 画面と操作、記録（localStorage）
- `sw.js` オフライン用

ローカルで動かすとき：`python3 -m http.server 8765` → http://localhost:8765/
